# Airbnb Pricing & Customer Intelligence System

An end-to-end data analytics project focused on analyzing Airbnb listings, pricing, hosts, availability, and customer review activity. The project uses Python for data preparation and analysis, MySQL and SQL for business-focused querying, and Power BI to create an interactive dashboard.

## Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* MySQL
* SQL
* Power BI
* Excel / CSV

## Project Workflow

```text
Raw Data
   ↓
Data Cleaning & Preprocessing
   ↓
Feature Engineering
   ↓
MySQL Database
   ↓
SQL Analysis
   ↓
Power BI Dashboard
   ↓
Business Insights
```

## Key Analysis Areas

* Airbnb pricing patterns
* Room type performance
* Host analysis
* Listing availability
* Customer review activity
* Customer engagement
* Business-oriented SQL analysis
* Interactive Power BI reporting

## SQL Analysis

The project includes:

* Basic SQL queries
* Aggregations
* Joins
* CTEs
* Window Functions
* Business Views

## Power BI Dashboard

The final dashboard presents the key findings through interactive visualizations, KPIs, slicers, and analytical charts, allowing users to explore Airbnb marketplace performance from different perspectives.
